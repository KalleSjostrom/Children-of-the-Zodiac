# Original Java source (reference only)

This is `src/` from commit a28bc8bffa280071f1eeb40b82391b16fee7c0bc ("Added project")
of https://github.com/KalleSjostrom/Children-of-the-Zodiac, the last version of the
game that compiled and ran (OpenGL 2 / JOGL). Later commits started a GL4 renderer
rewrite and village asset rework that were never finished ("THIS DOESN'T COMPILE").

The GDScript port in `src/` mirrors this tree file by file (see `docs/class_map.tsv`).
Godot ignores this folder (`.gdignore`).
