# Saves on a labyrinth floor, away from its save point, and loads that save
# (parity case dungeon_save_load, phase 2 rollout; COTZ-005: a save made in a
# labyrinth keeps the node and direction, "labpos"): --load="Slot 1"
# --start="<floor>-mark0" --no-encounters. A walk, the console's "save 2"
# (with --seed the save goes to user://saves_deterministic/, which loading
# reads first), the console's "goto Title Screen", Continue, Slot 2: the floor
# loads at the node and facing it was saved at; a walk there. No shot of the
# Continue list: it shows when each slot was saved (the file's time,
# SaveSlots), which differs from run to run.

wait 700

tap UP
wait 700
pos saved_at
shot v01_saved_at

log saved

wait 600

wait 600

wait 700

wait 700

wait 2000
