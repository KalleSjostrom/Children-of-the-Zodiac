* Heal X hp to Y character (including enemy)
* Godmode; take no damage
* Teleport to <list of exits>
* Teleport to nearest save
* Teleport to boss fight
* Show entire map
* Unlock path in world map
* Teleport to anywhere in the world
* This would replace the Cheater in the project
